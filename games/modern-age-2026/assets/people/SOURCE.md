# Modern Age character assets

Construction_Male_02, Construction_Female_01 and Military_Male_01 derive from [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox/tree/0943055db6ec570bcef9f2c8b41c9e5467c808f9/Assets/Avatars/Professions). The original copyright notice and MIT terms are in LICENSE.md. The game uses simplified skinned geometry, resized diffuse textures, six authored action cycles and directional WebP atlases rendered from the same models.
